# Medical Pharmacy Management System 💊

A simple **Medical Pharmacy Management System** designed to manage medicine details and track medicine expiry dates.

## Features ✨

* Add and manage medicine details
* Track medicine expiry dates
* View available medicines
* Update and delete medicine records
* Simple and easy-to-use interface

## Technologies Used 🛠️

* Python
* Flask
* HTML
* CSS
* JavaScript

## Installation 🚀

Clone the repository:

```bash
git clone https://github.com/sanskardhanorkar06-collab/medical-pharmacy-management.git
```

Go to the project folder:

```bash
cd medical-pharmacy-management
```

Run the application:

```bash
python app.py
```
